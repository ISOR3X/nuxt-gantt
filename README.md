# Nuxt Gantt

Gantt charts for Nuxt UI.

A work in progress project for creating gantt charts.

## Features

1. Tasks with progress and dependencies
2. Events/ deadlines
3. 2D virtualization
4. Save and load projects to JSON
5. Styling system similar to Nuxt UI
